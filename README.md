## ✨ Overview

An interactive, hardware-accelerated **3D Developer Portfolio** inspired by [MengTo/threeui](https://github.com/MengTo/threeui). Built using **Three.js**, **custom GLSL vertex & fragment shaders**, **React**, and **Tailwind CSS**, featuring dark glassmorphism aesthetics and real-time reactive physics.

---

## 🚀 Key Features

* **🌊 Dynamic Wave & Horizon Shader**: A custom GLSL shader canvas running in the hero section that perturbs vertex heights based on mouse cursor coordinates with fluid physics and horizon chromatic glows.
* **🧪 Interactive 3D WebGL Laboratory**: An interactive 3D testbed where visitors can touch, drag to rotate, switch meshes (Torus Knot, Icosahedron, Dodecahedron, Octahedron), toggle shader materials (Hologram, Chrome, Emerald Sheen, Wireframe), adjust speeds, and view live 60 FPS stats.
* **🎴 3D Perspective Tilt Cards**: Project cards that compute mouse position in real time to produce authentic physical perspective pitch/yaw and moving holographic reflections.
* **🤖 Featured Engineering Systems**:
  * **AI Architecture Compiler**: Multi-stage compiler converting natural language PRDs into structured database schemas, API contracts, and auth rules with SQLite runtime verification.
  * **Multi-Persona AI ChatBot**: Role-specific LLM agent system (Doctor, Teacher, Tech Support) with Cohere API and Flask.
  * **High-Performance LMS Engine**: C++ & Java capstone engineered with core DSA principles for low-latency queries.
  * **Lumière — 3D Women's Fashion Studio**: Teaser card for our upcoming 3D apparel e-commerce boutique.
* **📜 Interactive CV Modal & Print**: Built-in resume viewer with instant "Print / Save PDF" support.

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone git@github.com:Jayudaykiran/portfolio-3d.git
cd portfolio-3d
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 4. Production build
```bash
npm run build
```
